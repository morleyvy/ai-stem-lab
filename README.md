# Shoqan

Виртуальная STEM-лаборатория для школ Казахстана: химия, физика и биология без оборудования и реактивов. Кейс «STEM без сложного оборудования», WIT Teens Hackathon.

**Сайт:** https://ai-stem-lab.vercel.app — кнопка «Попробовать без регистрации» открывает всё без аккаунта.

Ученик сам проводит опыт: собирает электрическую цепь, наливает кислоту, двигает реостат, меняет длину маятника. Перед опытом он выдвигает гипотезу, после — видит разбор и отвечает на вопросы, которые ИИ составляет по этой работе. Учитель создаёт класс, выдаёт задания и видит результаты без проверки тетрадей.

## Возможности

**Для ученика**
- **21 лабораторная работа** по программе РК для 7–9 классов: 7 по химии, 7 по физике, 7 по биологии. Класс каждой работы определён по типовой учебной программе, источник указан в данных.
- **Фильтр по классам 7–11.** Для 10–11 классов пока показаны темы программы с пометкой «Скоро»: без выдуманного содержания.
- **Цикл работы:** гипотеза → опыт своими руками → лабораторный журнал (заполняется сам) → вывод → разбор гипотез и ответов → опрос на закрепление от ИИ.
- **Шоқан — ИИ-наставник.** Видит показания приборов в опыте ученика и отвечает про его установку, а не пересказом учебника. Готовых ответов на контрольные вопросы не выдаёт.
- **Детективные миссии.** В пробирках неизвестные вещества, число опытов ограничено. Ученик планирует опыты, делает вывод и объясняет его. Верность ответа проверяется детерминированно, ИИ оценивает только ход рассуждения.
- **Свободная лаборатория:** все реактивы и симуляции без заданий.
- **Прогресс:** уровни, баллы, серия дней, достижения, история работ.
- **Казахский и русский** — интерфейс, содержание работ и ответы ИИ. Крупный шрифт одной кнопкой.

**Для учителя**
- **Классы и задания:** класс с кодом для учеников, задания со сроком, таблица результатов класса.
- **ИИ-конструктор работ:** учитель описывает работу одной фразой («Закон Ома для 8Б, упор на реостат»), Шоқан собирает новую лабораторную на существующих симуляциях. Сервер проверяет каждый шаг: несуществующий регулятор или недостижимое значение не пропустит. Пока — физика и биология.
- **Живой урок:** учитель в реальном времени видит, кто из класса на каком шаге, кто застрял и какую ошибку делают чаще всего, и отправляет подсказку одному ученику или всем.

## Как устроено

```
Браузер (Vite, vanilla JS, SVG-сцены)
  ├─ движок химии src/engine.js + проверенная база реакций ──► что произошло в опыте
  ├─ симуляции src/sims/*.js (физика, биология)             ──► показания приборов
  ├─ Supabase: аккаунты, классы, результаты (RLS), Realtime для живого урока
  └─ /api/* (Vercel serverless) ──► Gemini или Claude: объяснения, чат, опрос, конструктор, отзыв о миссии
```

**ИИ не решает, что произойдёт в опыте.** Языковые модели иногда выдумывают химию, например что медь реагирует с разбавленной кислотой. Поэтому результат опыта всегда считает детерминированный движок по проверенной базе, а ИИ объясняет только по её фактам. Всё, что приходит от модели (опрос, работа из конструктора), сервер проверяет строгим валидатором перед показом.

**Без ИИ сайт тоже работает.** Если ключа нет или модель недоступна, запрос разбирается по ключевым словам (ru/kk), объяснения берутся из базы, а вместо ИИ-отзыва показывается статический.

## Запуск локально

```bash
npm install
cp .env.example .env   # вписать GEMINI_API_KEY или ANTHROPIC_API_KEY (без ключа — офлайн-режим)
npm run dev            # http://localhost:5173
npm test               # тесты валидатора конструктора и живого урока
```

Без ключей Supabase сайт работает в демо-режиме: прогресс хранится в браузере.

## Supabase (аккаунты, классы, живой урок)

1. Создать проект на supabase.com.
2. В **SQL Editor** выполнить по порядку: `supabase/schema.sql`, затем `002`–`006` из той же папки. Каждый скрипт можно запускать повторно.
3. **Authentication → Sign In / Providers → Email:** выключить **Confirm email**.
4. **Realtime → Settings:** выключить **Allow public access** — живой урок использует только приватные каналы.
5. Скопировать **Project URL** и ключ **anon public** в `.env`: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`.

| Миграция | Что добавляет |
|---|---|
| `schema.sql` | Профили и результаты, политики RLS |
| `002_classes_assignments.sql` | Классы с кодом и задания со сроком |
| `003_hardening.sql` | Ограничения на данные, лимиты частоты, смена кода класса |
| `004_custom_lessons.sql` | Работы из ИИ-конструктора: пишет автор, читают его ученики |
| `005_live_lessons.sql` | Живой урок: таблица сессий и политики Realtime |
| `006_revoke_trigger_execute.sql` | Закрывает прямой вызов служебной функции через API |

**Защита данных.** Учитель видит только учеников, вступивших в его класс по коду, и только их имя, класс и результаты. Телефон — лишь логин и в таблицы не попадает. Доступ ко всем таблицам и к каналам живого урока ограничен политиками RLS.

## Деплой (Vercel)

Проект подключён к GitHub: каждый push в `main` публикуется автоматически. Сборка `npm run build`, папка `dist`. В переменных окружения Vercel: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` и `GEMINI_API_KEY` или `ANTHROPIC_API_KEY`. Файлы `api/*.js` становятся serverless-функциями — ключ ИИ остаётся на сервере.

## Известные ограничения

- Вход по телефону без СМС-подтверждения: номер служит логином. СМС требует платного провайдера.
- Зарегистрироваться учителем может любой. Чужих учеников он не увидит без кода класса, но для реального запуска нужна проверка учителей школой.
- На живом уроке сервер не сверяет, чей прогресс публикует ученик: одноклассник может подменить отображение прогресса на панели учителя. На оценки это не влияет.
- Конструктор пока собирает работы только по физике и биологии.
- Нет общего лимита запросов к ИИ на уровне сервера: перед широким запуском стоит поставить лимит расходов у провайдера.
- В химии все вещества считаются взятыми в эквивалентных количествах, избыток реагента не моделируется.
