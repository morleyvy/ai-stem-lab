# Shoqan

Виртуальная лаборатория по химии, физике и биологии для школ Казахстана. Проект для WIT Teens Hackathon, кейс «STEM без сложного оборудования».

Сайт: https://shoqanlab.vercel.app (можно зайти без регистрации)

## Что это

Во многих школах нет нормальной лаборатории, и опыты ученики видят только на картинке в учебнике. Мы сделали сайт, где опыт можно провести самому: собрать цепь, налить кислоту, подвигать реостат, поменять длину маятника.

Сейчас на сайте 21 лабораторная работа для 7–9 классов, по 7 на каждый предмет. Класс для каждой работы мы сверили с типовой учебной программой РК. Для 10–11 классов пока только список тем, которые хотим добавить.

Работа идёт так: сначала ученик выбирает гипотезу, потом делает опыт, журнал заполняется сам. В конце показывается, какие гипотезы подтвердились, и ИИ задаёт несколько вопросов по этой работе.

Ещё есть:
- чат с ИИ-помощником Шоқаном, он видит показания приборов в опыте и отвечает именно про них;
- детективные миссии: в пробирках неизвестные вещества, нужно за несколько опытов понять, где что;
- свободная лаборатория со всеми реактивами;
- уровни, баллы и достижения;
- казахский и русский язык;
- работа без интернета: после первого захода сайт и все опыты открываются офлайн, его можно поставить на телефон как приложение. Без сети Шоқан отвечает из проверенной базы: показания приборов, формула, объяснение реакции из движка и частые вопросы про сайт. Без сети не работают только свободные ответы ИИ и сохранение в журнал класса.

Для учителя:
- классы с кодом для учеников, задания со сроком и таблица результатов;
- конструктор: учитель пишет, какую работу хочет, и ИИ собирает её из наших симуляций (пока только физика и биология);
- живой урок: видно, кто из класса на каком шаге и кто застрял, можно отправить подсказку.

## Почему ИИ не решает результат опыта

Нейросети иногда ошибаются в химии, например могут сказать, что медь реагирует с разбавленной кислотой. Поэтому что произойдёт в опыте, считает наш движок по базе реакций (`src/data/reactions.js`), а ИИ только объясняет. То, что генерирует ИИ (вопросы, работы из конструктора), сервер проверяет перед тем, как показать.

Если ключа ИИ нет, сайт всё равно работает, просто без чата и сгенерированных вопросов.

## Запуск

```bash
npm install
cp .env.example .env   # ключ GEMINI_API_KEY или ANTHROPIC_API_KEY, можно без него
npm run dev            # http://localhost:5173
npm test
```

Без Supabase сайт работает в демо-режиме, прогресс сохраняется в браузере.

## Supabase

1. Создать проект на supabase.com.
2. В SQL Editor выполнить `supabase/schema.sql`, потом файлы `002`–`006` по порядку.
3. Authentication → Email: выключить Confirm email.
4. Realtime → Settings: выключить Allow public access (нужно для живого урока).
5. Вписать Project URL и anon key в `.env` (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`).

Миграции:
- `schema.sql` — профили и результаты
- `002` — классы и задания
- `003` — ограничения и лимиты
- `004` — работы из конструктора
- `005` — живой урок
- `006` — закрывает лишний доступ к служебной функции

Учитель видит только учеников своего класса, вступивших по коду. Номер телефона используется только как логин. Доступ к данным ограничен политиками RLS.

## Деплой

Сайт на Vercel, обновляется при каждом push в `main`. В настройках Vercel нужны `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` и ключ ИИ. Папка `api/` становится serverless-функциями, поэтому ключ ИИ не попадает в браузер.

## Где что лежит

- `src/main.js` — меню, кабинет учителя, профиль
- `src/lesson.js` — прохождение работы
- `src/data/` — работы, реакции, миссии, темы по классам
- `src/engine.js` — движок химических опытов
- `src/sims/` — симуляции по физике и биологии
- `src/svg/` — рисунки опытов
- `src/chat.js` — чат с Шоқаном
- `src/missions.js` — миссии
- `src/constructor.js` — конструктор работ
- `src/live.js` — живой урок
- `src/i18n/` — казахский перевод
- `server/`, `api/` — запросы к ИИ
- `supabase/` — база данных
- `tests/` — тесты

## Что пока не доделано

- Нет подтверждения номера по СМС, для этого нужен платный сервис.
- Учителем может зарегистрироваться кто угодно. Чужих учеников он не увидит, но в школе учителей надо проверять.
- На живом уроке ученик теоретически может подменить прогресс одноклассника на экране учителя. На оценки это не влияет.
- Конструктор пока не делает работы по химии.
- Нет общего лимита запросов к ИИ.
- В химии не учитывается количество вещества.
