# AI STEM Lab

Виртуальная химическая лаборатория для школьников 8–9 класса. Кейс «STEM без сложного оборудования», WIT Teens Hackathon.

Виртуальный лабораторный практикум. Ученик сам проводит опыт на 3D-лабораторном столе: наливает растворы, помещает металлы в стакан, нагревает плитку. Реакция идёт вживую.

- **Лабораторные работы (5 тем программы 8–9 класса).** Каждая построена по схеме школьного практикума: цель, реактивы и техника безопасности, ход работы, контрольные вопросы, вывод. Перед каждым опытом ученик выдвигает гипотезу. Лабораторный журнал (опыт, гипотеза, наблюдения, уравнение) заполняется автоматически.
- **Свободный эксперимент.** Доступны все реактивы. ИИ-ассистент по описанию идеи отмечает на столе нужные реактивы, но опыт ученик проводит сам.
- **ИИ-ассистент** по кнопке объясняет результат опыта. Он опирается только на факты из проверенной базы.

## Как это работает

```
Запрос ученика ──► ИИ (Gemini/Claude) разбирает запрос в JSON  ──┐
                   (только вещества из нашего списка)     │   офлайн: разбор по ключевым словам
                                                          ▼
                     Проверенная база реакций (src/data/reactions.js)
                     решает, ЧТО произойдёт при этой t° и концентрации
                                                          │
                     ┌────────────────────────────────────┴───────────┐
                     ▼                                                ▼
          3D-сцена (three.js):                        ИИ-учитель объясняет «почему»
          цвет, пузыри, осадок, растворение           только по фактам из базы
```

**Почему ИИ не решает, что произойдёт в опыте.** Языковые модели иногда выдумывают химию. Например, они могут сказать, что медь реагирует с разбавленной кислотой. Для учебного продукта это недопустимо, поэтому результат опыта всегда берётся из проверенной базы. Если комбинации в базе нет, лаборатория честно отвечает «не моделируется» и не угадывает.

**Работает без интернета.** Если ИИ недоступен, запрос разбирается по ключевым словам (русский и казахский), а объяснение берётся из базы.

## Запуск

```bash
npm install
cp .env.example .env   # вписать GEMINI_API_KEY или ANTHROPIC_API_KEY (без ключа — офлайн-режим)
npm run dev            # http://localhost:5173
```

## Аккаунты (Supabase)

После входа ученик выбирает «Эксперименты по темам» или «Самостоятельные эксперименты». Учителю дополнительно доступны «Результаты класса».

Настройка (один раз):
1. Создать проект на supabase.com.
2. В разделе **SQL Editor** выполнить файл `supabase/schema.sql`.
3. В разделе **Authentication → Sign In / Providers → Email** выключить **Confirm email**.
4. Скопировать **Project URL** и ключ **anon public** (Project Settings → API) в `.env`: `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.

Без ключей приложение работает в демо-режиме без аккаунтов.

**Защита данных.** Учитель видит только тех учеников, которые вступили в его класс по коду, и только их имя, класс и результаты. Телефон хранится лишь как логин и в таблицы не попадает. Все ограничения заданы политиками RLS в `supabase/schema.sql`.

## Деплой (Vercel)

Сайт: https://ai-stem-lab.vercel.app. Проект подключён к репозиторию на GitHub — каждый push в ветку main автоматически публикуется.

1. Залить проект на GitHub и импортировать его в Vercel. Сборка: `npm run build`, папка вывода `dist`.
2. В настройках проекта добавить переменные окружения `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` и `GEMINI_API_KEY` (или `ANTHROPIC_API_KEY`).
3. Файлы `api/parse.js` и `api/explain.js` автоматически станут serverless-функциями. Ключ остаётся на сервере.

## Структура

| Файл | Что делает |
|---|---|
| `src/data/substances.js` | Справочник веществ и ключевые слова для офлайн-разбора |
| `src/data/reactions.js` | Проверенная база реакций: условия, уравнения, наблюдения, объяснения |
| `src/engine.js` | Детерминированный движок: параметры → результат опыта |
| `src/scene.js` | 3D-лаборатория на three.js: наливание, бросание, реакции |
| `src/main.js` | Навигация: список работ, работа, свободный эксперимент |
| `src/data/lessons.js` | Сценарии лабораторных работ |
| `src/lesson.js` | Проведение работы по шагам и лабораторный журнал |
| `src/sandbox.js` | Свободный эксперимент и ИИ-ассистент |
| `src/bench.js` | Состояние стола: содержимое стакана, температура, результат |
| `src/data/shelf.js` | Что стоит на столе (склянки, чашки с металлами) |
| `src/localParser.js` | Офлайн-разбор запроса |
| `server/ai.js` | Промпты: разбор запроса и объяснение |
| `server/providers.js` | Gemini или Claude — выбирается по заданному ключу |
| `server/handlers.js` | HTTP-логика, общая для Vite (разработка) и Vercel (продакшн) |

## Как добавить реакцию

Добавь запись в `REACTIONS` в `src/data/reactions.js`: реагенты, условия, уравнение, наблюдения и объяснение. Если нужно новое вещество, сначала добавь его в `src/data/substances.js`. Проверь уравнение по учебнику: база — источник истины.

## Известные ограничения

- Вход по телефону без СМС-подтверждения: номер используется как логин (внутренний email вида 7XXXXXXXXXX@phone.ai-stem-lab.local). Подтверждение по СМС требует платного провайдера (Twilio и т.п.). Поэтому формально кто угодно может зарегистрировать чужой номер.
- Зарегистрироваться «учителем» может любой. Чужих учеников такой «учитель» не увидит без кода класса, но для реального запуска нужна проверка учителей школой.

- Нет ограничения частоты запросов к ИИ. Если выложить публичную ссылку, ключом могут злоупотребить. Перед публикацией стоит поставить лимит расходов в консоли Anthropic.
- Все вещества считаются взятыми в эквивалентных количествах, избыток реагента не моделируется.
